Requirements

Before using Skylark Edition 26, make sure the following requirements are met.

  • Server access: You must have access to Skylark servers. If you don't, request access.
  • Shortcuts permissions: Configure the necessary Shortcuts security and sharing permissions for your software version. Apple may change their names and locations.
  • iCloud: iCloud must be enabled and available for Skylark’s iCloud-based functionality.
